### Restriction Enzyme Analysis

This was an assignment completed as part of a graduate-level Bioinformatics Programming course.

The program:

- Reads a nucleotide sequence from a FASTA file.
- Reads restriction enzymes and their recognition sites from a text file.
- Identifies restriction enzyme cut sites in the DNA sequence.
- Generates resulting DNA fragments.
- Produces a formatted report showing cut sites, fragment counts, lengths, and sequences.
  
**Languages used:** Python
